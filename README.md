# 別衝動

視訊交友詐財與性勒索防制｜男性向互動教材（國中小・高中）

> 正妹主動找你、狂誇你、約你視訊——

**線上使用：** https://10033641tycg.github.io/pause-first/

## 這是什麼

一套用手機聊天介面呈現的互動教材，模擬男生最常遇到的視訊詐財型性勒索：陌生帳號主動搭訕、很快約視訊、對方先做給你看再要你跟著做，接著翻臉說「我錄影了」，要你買點數或轉帳。

這類手法的核心是**快、急、讓你來不及想**，所以關鍵時刻設有倒數計時；猶豫到時間到，系統會判定「手先動了」，讓孩子親身體驗衝動下根本沒在想的那幾秒。

情境取材自實務案件的常見型態，加以改編、虛構，不代表任何特定個案，不含露骨內容；對方「先做給你看」的段落只以旁白點到為止。

## 適用對象與使用原則

- 對象為**國中小**與**高中／高職**男生。國中小版被勒索的標的是遊戲點數，高中版是轉帳與超商代碼。
- **用於個案時，請由受過訓練的專業人員全程陪同**，不要讓個案單獨使用。

三關完成後解鎖統整報告，整理孩子最容易中招的類型：衝動（腦袋還沒跟上手先動）、貪好處、怕被笑不敢拒絕、被威脅就慌。

## 設計原則

**不羞辱。** 復盤一開始就說清楚：會心動、會衝動是正常的，青春期本來就這樣；問題不在你有慾望，在於有人專門設計來利用它。

**求助具體。** 被勒索時不要付錢、不要再傳、不要刪對話；截圖蒐證，告訴信任的大人，撥 165 反詐騙或 113。

## 給陪伴者的功能

- **檢視結果**：保留孩子第一次自己作答的內容，重玩不會覆蓋。建議問法是「當下那幾秒，你腦子裡在想什麼？」
- **清除紀錄**：換下一位使用前請先清除。
- **資料不外傳**：作答資料只存在該裝置的瀏覽器中。
